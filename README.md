# hybrid-pqc-tls-poc

PoC: TLS 1.3 mit hybridem Post-Quantum-Key-Agreement (`X25519MLKEM768`) auf
Java 25 / IBM Semeru Runtime Certified Edition für z/OS, mit Erweiterungspfad
auf den IBMJCECCA-Provider (ICSF/CCA-Hardware) für den PQC-Anteil.

> Umsetzungsstand.
